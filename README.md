# CargoOptimizer (M/T ADA)

Kimyasal tanker **M/T ADA** (5.707 DWT) için IBC Code'a uygun yük stowage (istif) ve segregasyon optimizasyon aracı.

Kaptan ve yük operatörleri için tehlikeli yüklerin tanklara dağılımını, IBC Code segregasyon kurallarını ve uyumluluk kontrollerini çevrimdışı olarak hesaplar.

## Özellikler

- IBC Code'a göre segregasyon (ayrıştırma) kuralları
- Tank bazlı yük dağılım planı
- Uyumsuzluk (incompatible) uyarıları
- M/T ADA 5.707 DWT gemi profiline özel
- Tamamen tarayıcıda çalışır — internet gerekmez
- Tek dosya `index.html`, çift tıklayıp açılır

## Kullanım

`index.html` dosyasına çift tıklayın, tarayıcıda açılır. Başka kurulum gerekmez.

## Teknoloji

- HTML5 / CSS3 (Vanilla)
- JavaScript (ES6+)
- Harici bağımlılık yok
